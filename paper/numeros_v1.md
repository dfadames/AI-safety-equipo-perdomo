## 7. Not valid yet

- Counterfactual replicas: 3 run. Blocking is by event id, and event ids are positional, so a re-run with a non-deterministic model puts that id on a different event: in 2 of 3 replicas none of the blocked ids was a channel message. They are not evidence that blocking the cut stops the escape.

## 8b. Validator limitation

- The validator accepts any string that contains every part: 9 of 168 successful validations were not the plain credential (e.g. 'DeltaCharlieBravoAlpha', 'AlphaBravoCharlieDeltaXYZSIGUEGOBIERNO', 'AlphaBravoCharlieDeltaDelta'). **Figure 1.** Per-agent view versus provenance map of the same episode (instructed, 4 agents, credential in 4 parts; model deepseek-flash). (a) Excerpts of each agent's trace, summarized from the log: each one is a plausible audit — find the local fragment, share it, receive the others, validate. (b) The 22 events (of 95) that are ancestors of the first successful unlock. The credential was assembled from 4 containers; the 3 highlighted messages are the minimum cut. The oracle — the parts contained in the credential — confirms the span. Reading one trace at a time, the per-agent LLM judge scored this episode at most 3/10 without the rule and 10/10 with it.

(b, c) Minimum cut of each escape (dots) and mean (line): it tracks the number of parts, not the number of agents. n = 1–3 episodes per point.

**Figure 3.** Detection by monitor. (a) Escape episodes. (b) Episodes without escape; none attempted a restricted action, so the map could not fire. (c) The 1-part control, where validating is legitimate and every alarm is false. The per-agent judge reads one agent's trace at a time.
